# 🌱 First English — English from Zero

A visual-first, sound-first English learning app for absolute beginners of any age — toddlers to adults. No English needed to start: everything is taught through pictures, a friendly owl guide 🦉, and spoken audio.

**Live:** https://builtbysai.com/first-english/

## How it works

- **Letters in phonics order** (`s a t i p n …` — the Jolly Phonics sequence used in schools worldwide), not A-B-C, so the first six letters already make real words
- **5 steps per level:** Sounds → Listen → Build (blend) → Read → Story
- **Every word is decodable** from letters already taught — no guessing from pictures
- **Gentle, non-punitive** — mistakes just get a "try again"; stars and streaks reward daily 5-minute sessions
- **Parent gate** (press & hold ⚙️) explains the method, with voice test and progress reset
- Progress saved on-device; works offline once loaded

## Pedagogy notes

- Synthetic phonics: sounds before letter names; confusable letters (b/d, p/q) separated
- Montessori 3-period lesson shape (this is… / show me… / what is this?)
- Pure sounds modeled by the grown-up (ssss, not "ess"); the app speaks whole words and sentences via the Web Speech API at a slowed rate
